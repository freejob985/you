# نظام إدارة كورسات يوتيوب

## المميزات
- إضافة وإدارة كورسات من يوتيوب
- تتبع تقدم المشاهدة
- البحث في الدروس
- قائمة سياقية للوصول السريع
- واجهة مستخدم سهلة الاستخدام

## المتطلبات
- PHP 7.4+
- SQLite3
- متصفح حديث يدعم JavaScript

## التثبيت
1. نسخ الملفات إلى مجلد الويب
2. التأكد من صلاحيات الكتابة لملف قاعدة البيانات
3. تكوين مسار قاعدة البيانات في `database.php`

## الاستخدام
- النقر بزر الماوس الأيمن في أي مكان لفتح القائمة السريعة
- استخدام شريط البحث للعثور على الدروس
- إضافة كورسات جديدة من صفحة "إضافة كورس"

## التطوير المستقبلي
- إضافة دعم متعدد المستخدمين
- تحسين أداء البحث
- إضافة ميزات مزامنة إضافية
